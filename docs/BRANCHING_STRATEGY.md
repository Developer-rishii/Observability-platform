# Branching Strategy & Workflow

## Branch Structure
- `production`: Stable production-ready code.
- `dev`: Primary integration branch for active development.
- `feature/<feature-name>`: Topic/feature branches branched off `dev`.

## Commit Naming Conventions
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation updates
- `test:` Test additions/modifications
- `infra:` Infrastructure/Docker updates
- `agent:` Monitoring agent code
- `ml:` Machine learning service/model
- `correlation:` Incident correlation service
- `rag:` RAG retrieval service
- `ai:` Gemini AI integration
- `frontend:` Frontend UI updates
