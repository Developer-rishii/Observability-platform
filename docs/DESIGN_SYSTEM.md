# Design System & UI Guidelines

## Overview
This document outlines the design principles and UI component guidelines for the Observability Platform.

## Palette & Aesthetics
- **Background**: Deep Slate (`#0f172a`)
- **Card / Container**: Slate 800 (`#1e293b`) with border (`#334155`)
- **Primary Accent**: Electric Blue (`#3b82f6`)
- **Text Color**: `#f8fafc` (Primary) and `#94a3b8` (Muted)

## Core Components
- Metric Cards
- Logs Viewer
- Event Stream Timeline
- Incident Correlation Matrix
- AI Remediation Chat Widget
